# Changelog

All dates are 2026.

## v0.8.2 (test build) — 23 Nov
- **Crash on html.duckduckgo.com fixed** (first crash captured by the v0.8 crash handler: access violation in `qsort` under `g_setup` in `layout_grid.c`). The netsurf-switch grid code sorted items with a comparator that compared item addresses and never returned 0, not even for an item against itself; pdclib's quicksort has no bounds checks in its partition scans and walked off the array. The comparator now uses a document index (patch 15 in `tools/patch_netsurf.py`), and `qsort` is replaced program-wide by a bounds-safe insertion sort/heapsort in `src/xbox_libc.c` that cannot leave the array whatever the comparator returns (unit-tested with inconsistent and random comparators under ASan).
- Settings menu: no repaint of the page between successive menus (`nsx_menu_keep`), which caused the flicker on every change.
- Start-up splash: `res/splash.png`, generated by `tools/make_splash.py` from NetSurf's own logo with "Original Xbox Edition" and the version; shown while fonts, history and cookies load, at least 2 s, skippable with any button; edge pixels extend it to larger video modes.

## v0.8.1 (test build) — 23 Nov
Compared against the other NetSurf console ports (Switch, 3DS) and upstream NetSurf. The Switch fork has no newer commits and the 3DS port is older than our base; upstream NetSurf and its libraries had fixes the fork lacks. They are now kept as patches in `tools/upstream/<tree>/` and applied in order by `tools/patch_netsurf.py` (verified on a pristine fork):
- libcss: `calc()` division by zero (SIGFPE crash, 113dc45), reads past the token vector in `calc()` and media lists (499f1c4, 006ffc4), `vh`/`vw` swapped (cbbeaaf), lengths rounded to the nearest pixel instead of truncated (5a55fad, dd7fad1, 5400b30, 204bad0, e6f6795, 2212165), saturating fixed-point add/subtract (625edc4, d1e0b2a ported), flex shorthand (ef5dbb1, 0c4f519), inline-style cascade origin (6d1a9ff), relative positioning (1e18694, 58bff86), column-gap percentages (83c4d9a), `calc()` whitespace (383b7bc), `::first-letter` (628abea).
- libnsgif: LZW off-by-one (2255b2f), use of an unallocated previous frame (69c1120), background restore (5f64dc9).
- libnsbmp: RLE trailing padding and odd widths (c958054, 3e54099, 66ca447).
- libsvgtiny: DOM string leaks and error-path fixes (d3ad22d, 1785d0d, caae4d6), safer float→int in gradients (aea9336).
- netsurf: `https://host:443/` normalised to the default port (597329f), bounded `realpath` fallback (703224c), corestrings init state (35e53fe), scripts inserted by JS (6ef837d).
- NetSurfX: `getcwd()` wrote one byte past a 3-byte buffer.

## v0.8.0 (test build) — 23 Nov
Stability
- Root cause of the Google freeze addressed: nxdk's `LWIP_PLATFORM_ASSERT` asserts its message string (always true), so when the kernel pool allocation in the NIC receive DPC failed, `rx_callback` wrote through a null pointer at DISPATCH_LEVEL. The frame is now dropped and returned to the NIC (patch in `tools/patch_nxdk.py`).
- Receive path sized for a browser: 128 NIC receive buffers and a 24-segment TCP window (was 64 buffers shared by every socket with a 45-segment window each). `LWIP_DEBUG` compiled out.
- Unhandled exceptions: nxdk's `WinapiThreadStartup` (every thread, `main()` included) now runs under an SEH frame calling the filter set with a new `SetUnhandledExceptionFilter`. NetSurfX's filter writes `NSX-CRASH.LOG` (exception, registers, likely return addresses), shows a crash screen and reboots to the dashboard; at DISPATCH_LEVEL it never touches the file system. `tools/symbolize.py` maps the addresses with `nsx.map`.
- Logs are durable: `NtFlushBuffersFile` after `fflush` (every 2 s and on every page load/event), so `NETSURF.OLD` survives a freeze or power cycle.
- Watchdog: on-screen notice after 8 s, `NSX-HANG.LOG`, automatic return to the dashboard after 3 minutes. Heartbeat/phase are atomics (TSan-clean).
- `_xbox_assert` is IRQL-aware: no file I/O at DISPATCH_LEVEL (deferred to the main loop).
- NetSurf fixes: find-in-page leaked its match-list head; contents destroyed without being closed leaked their search context; empty resources passed `NULL` to `memcpy`.

Google
- Google Search (and the Google home page) is answered locally with a redirect to DuckDuckGo HTML, keeping the query (`src/xbox_rewrite.c`, unit-tested). Setting: *Google searches*.

Performance
- TLS: P-256 offered first (fastest key exchange in mbedTLS on a 32-bit P3); TLS 1.3 session tickets captured after the handshake for resumption.
- Memory cache sized from free RAM at start-up (an eighth, 3–8 MB); `memory_cache_size:0` = automatic.

English
- The whole UI, help, on-screen keyboard (now with Western European accents), home page, README, settings and logs are in English. `Accept-Language: en-US, en`, US keyboard layout by default. Log tags are now `[NET]`, `[PERF]`, `[ERROR]`; files `NSX-HANG.LOG`, `NSX-ERROR.LOG`, `NSX-CRASH.LOG`, `data\CLEAR.TXT`.
- Search engines: DuckDuckGo (HTML, default), DuckDuckGo Lite, Wikipedia (en), Mojeek, FrogFind.

## v0.7.2 (test build) — 13 Nov
- Fixed a hard freeze ("Assertion failed … strtof") on pages with modern CSS: nxdk's `strtod`/`strtof`/`strtold`/`atof` are `assert(0)` stubs. NetSurfX now ships its own (tested against glibc on 200,000 inputs), plus `lroundf`/`llroundf` used by SVG rendering.
- The nxdk/pdclib `printf` family ignores `%f/%e/%g` without consuming the argument, which shifted every following argument. Replaced with stb_sprintf (public domain).
- Link-time audit: no `assert(0)` stub from nxdk is referenced any more.
- `_xbox_assert` overridden: failed assertions are logged to `NSX-ERRO.LOG` instead of halting the CPU.

## v0.7.1 (test build) — 13 Nov
- Diagnostics on by default: `NETSURF.LOG` (flushed every second, capped at 8 MB, previous session kept as `NETSURF.OLD`), `[REDE]` per-request timings, `[PERF]` page times, heap and free-memory stats, slow-redraw reports.
- Watchdog thread writes `NSX-BLOQUEIO.LOG` when the main loop stalls for more than 8 s.
- Optional on-screen stats in the status bar.

## v0.7 — 13 Nov
- D-pad spatial navigation between links and form fields.
- Streaming downloads straight to disk (memory-safe for large files), with progress, cancel, redirect following and FATX-safe file names; E:/F:/G: partitions mounted.
- "Site version" setting: normal, mobile, light (Opera Mini) or text (Links) user-agent.

## v0.6 — 13 Nov
- HTTP keep-alive connection pool with dead-connection retry; in-app DNS cache.
- Disk cache in `D:\cache` (64 MB); a failing cache no longer prevents startup.
- Fast `memcpy`/`memmove`/`memset`/`memcmp`/`strlen` (pdclib's versions are byte-by-byte).
- lwIP socket table raised from 4 to 16 — image-heavy pages were silently failing.
- Cookies, history and the cache index are now saved on every exit path, including in-game reset.
- Start menu, persisted history, find in page, settings screen, clear browsing data.
- USB keyboard (Portuguese/US layouts, dead keys) and mouse support.

## v0.5 — 13 Nov
- Rebased on the netsurf-switch fork: CSS grid, custom properties, `calc()`, gradients, shadows, rounded corners, `<details>`/`<dialog>`/`[hidden]`.
- Two upstream flexbox fixes (inline children are now blockified; `flex: 1` distributes space equally).
- Web fonts (TTF/OTF and WOFF via an in-house converter) with memory caps and eviction.
- SVG (libsvgtiny + vendored expat) and WebP (vendored libwebp decoder).
